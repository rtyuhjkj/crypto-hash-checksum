# crypto-hash-checksum

Optimized SHA-256 and BLAKE3 multi-threaded chunked file checksum calculator.

[![CI](https://github.com/placeholder/crypto-hash-checksum/actions/workflows/ci.yml/badge.svg)](#)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

## Overview
A lightweight, high-reliability Python utility package developed for cloud-native microservices and pipeline health processing.

## Quickstart
```bash
pip install -r requirements.txt
python crypto_hash_checksum/core.py
```

## Running Tests
```bash
python -m unittest discover tests
```
